# Biblioteca escolar

Modernização da biblioteca da rede: acervo multiunidade, empréstimo, leitura de código e consulta online.

Composer: `buriti/i-educar-biblioteca-package`

## Para que serve

Evolui a gestão bibliotecária do i-Educar para operação multiunidade — acervo, circulação, leitor/webcam e consulta pelos usuários da rede e, quando habilitado, via app.

## Desenho de funções

| Função | Entrega |
| --- | --- |
| Acervo multiunidade | Obras e exemplares por unidade/escola |
| Empréstimo e devolução | Circulação com regras de prazo e situação do leitor |
| Leitor / webcam | Identificação rápida de obra e usuário |
| Consulta online | Pesquisa de acervo para comunidade escolar |
| Relatórios | Movimentação e indicadores de uso |

## Quem usa

- Bibliotecários e monitores
- Professores e alunos
- Famílias (consulta via app)

## Integrações

- Núcleo (pessoas/alunos)
- Módulo legado de biblioteca (convivência/modernização)
- Apps API
